Descripción del Puesto

Buscamos un Analista de Datos Senior apasionado por extraer insights de conjuntos de datos complejos para guiar decisiones estratégicas. Trabajarás estrechamente con los equipos de producto y marketing para entender el comportamiento del usuario y optimizar nuestras plataformas.

El candidato ideal tiene una sólida base analítica, excelente capacidad de comunicación para presentar hallazgos a stakeholders no técnicos, y experiencia comprobada en modelado de datos y creación de dashboards interactivos.

fact_check Requisitos

  • Dominio avanzado de SQL y Python (Pandas, NumPy).
  • Experiencia con herramientas de visualización (Tableau, PowerBI).
  • Nivel de inglés intermedio-avanzado.
