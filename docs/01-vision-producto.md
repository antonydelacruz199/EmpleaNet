# Visión del producto - EmpleaNet

## Nombre del sistema
EmpleaNet

## Descripción general
EmpleaNet es un sistema web orientado a la recopilación, búsqueda, filtrado y recomendación de oportunidades laborales. Su propósito es centralizar ofertas de empleo provenientes de distintas fuentes, permitir al usuario encontrar oportunidades relevantes y mostrar recomendaciones según su perfil académico y profesional.

## Problema que resuelve
Actualmente, las ofertas laborales suelen encontrarse dispersas en múltiples portales, redes y páginas de empresas. Esto dificulta la búsqueda eficiente, incrementa el tiempo invertido por el usuario y reduce la visibilidad de oportunidades relevantes.

## Propuesta de valor
EmpleaNet centraliza ofertas laborales, las normaliza, permite filtrarlas y recomienda las más adecuadas según el perfil del usuario.

## Objetivo del sistema
Construir un sistema web que permita:
- recopilar ofertas laborales desde fuentes externas
- centralizar las ofertas en una sola plataforma
- buscar y filtrar oportunidades de empleo
- recomendar empleos según el perfil del usuario

## Perfil de usuario objetivo
- estudiantes universitarios
- egresados
- usuarios que buscan oportunidades laborales acordes a su perfil

## Estado actual del proyecto
El proyecto se encuentra en fase inicial de arquitectura y construcción del MVP.
